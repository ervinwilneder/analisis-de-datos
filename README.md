# Análisis de datos

**Este libro se mudó a [ervinwilneder.ai/libro/analisis-de-datos](https://ervinwilneder.ai/libro/analisis-de-datos)**, donde se publica su segunda edición: los capítulos de la primera edición revisados, con lecturas actualizadas, y una parte nueva sobre el análisis de datos en la era de la IA.

Este repositorio conserva el código fuente (Quarto) de la primera edición, escrita en 2023 como material de cursada de la Diplomatura Universitaria en Programación de la UTN Haedo. Las páginas que se publicaban con GitHub Pages desde `docs/` ahora redirigen a la nueva dirección (con meta refresh, `location.replace` y un enlace visible), conservando el ancla de la sección si la había.
